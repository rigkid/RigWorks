# `rig.mod.binding`

| Field | Type | Meaning |
|-------|------|---------|
| `source` | entity | Modulator entity (e.g. LFO) |
| `target` | entity | Driven entity |
| `propertyKey` | string | Field name / path (same style as tween) |
| `depth` | float | Scale |
| `min` | float | Clamp |
| `max` | float | Clamp |
| `additive` | bool | Add vs replace |
