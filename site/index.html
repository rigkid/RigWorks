Pain

Rig

  1. Work locked in the app

    A scene, a show, a panel — each lives in a private file. Moving it means a converter. Converters rot.

    The document is the artifact

    Plain JSON. Named components on entities. Same schema ids — present, play, or print without a bridge.

  2. Tools and UI do not travel

    Write a control panel for one app and you rebuild it for the next. The knobs stay trapped with the chrome.

    Share the tool — UI moves too

    Author a tool in App A. Load the same document in App B. Controls, groups, actions still turn the same fields. The interface is data.

  3. Agents reinvent the format

    Each session invents its own JSON. The next agent burns tokens decoding a private dialect — or starts over.

    Agreement saves tokens

    One skill, one catalog, one validator. An agent writes Rig; the next session already accepts it. The cheapest token is the one never spent explaining a private format.
