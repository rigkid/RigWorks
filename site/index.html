Every creative-coding tool speaks only to itself

Move a scene from Processing to TouchDesigner, or a shader rig into a game engine, and you are rewriting it by hand or duct-taping a one-off exporter. Rig is the shared vocabulary that makes that translation unnecessary in the first place.

How it works

Rig documents are entities made of typed components — a transform here, a shape there, a light, a timing binding. No engine required to describe a scene; only required to run one.

Read the schema reference

Built for AI

Rig ships a JSON Schema for every component, reference examples, a validator that returns exact JSON Pointer errors, and a Claude Skill — so an agent can generate a document, get precise feedback, and self-correct without you in the loop.

AI co-coding · Agent skill · llms.txt

Honest limitations

Rig is at 0.x. Schema fields may still shift before 1.0. The honest price of a shared vocabulary: some flexibility any single tool would have is traded for portability across all of them.
